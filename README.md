# SET100 Investment Research Dashboard

Dashboard ภาษาไทยสำหรับข้อมูลหุ้นและงานวิจัย SET100

## รู้จักธุรกิจ

ทุกการ์ดเริ่มจากบริษัททำอะไร ลูกค้าคือใคร และช่องทางหารายได้ พร้อมตัวแปรที่ใช้ติดตามรายได้ แหล่งอ้างอิง และวันที่ตรวจข้อมูล

`business_profiles.json` เป็นคำอธิบายภาษาไทยที่เรียบเรียงจากหน้าลักษณะธุรกิจ SET/Settrade ของแต่ละบริษัท มีแหล่งบริษัทเพิ่มเติมเมื่อหน้าสรุปให้ข้อมูลไม่พอ ข้อมูลส่วนนี้เป็นคำอธิบายรูปแบบธุรกิจ ไม่ใช่ตัวเลขหรือสัดส่วนรายได้แยกส่วนงานของ Q3 และวันที่ตรวจข้อมูลไม่ใช่วันสิ้นงบ แยกรายได้ขาย ส่วนแบ่งกำไร และเงินปันผลให้ชัดเจน โดยเฉพาะบริษัทโฮลดิ้ง

แก้ไขคำอธิบายพร้อมตรวจแหล่งอ้างอิงในไฟล์นี้ จากนั้นใช้ `python scripts/apply_business_profiles.py` เพื่อใส่ใน `data.json` หรือให้ Workflow แปลง Excel ทำงาน ตัวแปลง Excel จะคงคำอธิบายจากไฟล์นี้ และการอัปเดตราคาหรืองบไม่เขียนคำอธิบายใหม่อัตโนมัติ ตรวจความครบถ้วนด้วย `python scripts/apply_business_profiles.py --check`

## วันที่และงวดข้อมูล

- ราคาและมูลค่าตลาดมีวันที่/เวลาต้นทาง (`marketDataAsOf`)
- P/E และ P/BV มีวันที่สถิติแยกจากราคา (`valuationRatiosAsOf`)
- งบระบุปีบัญชี งวดสะสม วันสิ้นงบ แหล่งข้อมูล วันตรวจ และสถานะสอบทาน
- กำไรไตรมาสและกำไรสะสมใช้หน่วยล้านบาท; แปลงจากพันบาทของ SET
- YoY ในการ์ดคือกำไรสะสมเทียบงวดเดียวกันปีก่อน ไม่แสดงเปอร์เซ็นต์เมื่อฐานเดิมเป็นศูนย์หรือติดลบ
- บทวิเคราะห์ หนี้/EBITDA และ EV/EBITDA มีงวด/วันที่เดิมกำกับ การอัปเดตตัวเลขไม่ถือเป็นการทบทวนบทวิเคราะห์

## ระบบอัปเดต

`update-data.yml` ทำงานตามเวลาเดิมและสั่งเองได้:

1. `scripts/update_data.py` อัปเดตราคาและตรวจรายชื่อ
2. `scripts/update_financial_data.py` อ่านข้อมูล SET ผ่าน Settrade รวมประกาศ F45 ที่พบ แล้วอัปเดตข้อเท็จจริงและวันที่
3. `scripts/update_set_index.py` อัปเดตดัชนี
4. บันทึกข้อมูลกลับ GitHub และ GitHub Pages เผยแพร่เว็บไซต์

ตัวอ่าน Settrade อ่านข้อมูล SSR ด้วยตัวแปลง literal ที่ไม่รัน JavaScript จากเว็บไซต์ ไม่ต้องติดตั้งไลบรารีเพิ่ม

`financial_snapshots.json` เก็บตัวเลขงบและที่มาที่ตรวจยืนยันแล้ว ช่วยป้องกัน Excel รุ่นเก่าเขียนทับงบใหม่ ส่วน `financial_update_status.json` เก็บรายงานรายบริษัท การอ่านแหล่งข้อมูลล้มเหลวจะคงค่าที่ตรวจไว้เดิมและแสดงสถานะตรวจไม่สำเร็จ ไม่สมมติว่าข้อมูลเป็นปัจจุบัน

การตรวจใช้ชุดงบล่าสุดของ Settrade และข่าวทางการที่หน้าแหล่งข้อมูลส่งกลับ จึงไม่ใช่การรับรองว่าไม่มีประกาศใหม่ที่ยังไม่ปรากฏในชุดข้อมูล หากพบประกาศงบใหม่แต่ยังอ่านตัวเลขไม่ได้ จะแสดง “มีงบใหม่ — ตัวเลขรอตรวจสอบ” พร้อมลิงก์ประกาศ

`update-dashboard.yml` แปลง Excel และดูแลข้อความภาษาไทย แล้วตรวจงบ/ราคาอีกครั้ง Workflow ทั้งสองใช้คิวเดียวกันเพื่อลดการเขียนข้อมูลพร้อมกัน

## Master Excel

Master เก็บงานวิจัยและความเห็นทีม; ตัวเลขที่ยืนยันใหม่เก็บใน snapshot แยกด้วย การอัปเดตราคาตามรอบไม่เขียน workbook ทุกครั้ง

เมื่อต้องการซิงก์ข้อเท็จจริงล่าสุดกลับ Excel ให้รัน `python scripts/sync_master_facts.py` (ต้องมี openpyxl) โปรแกรมไม่เขียนคะแนนหรือบทวิเคราะห์ และไม่ใส่รายได้/EBITDA งวดเก่าลงในแถวงบใหม่

## ป้ายมูลค่าและข้อมูลคะแนน

Dashboard และ data.json ไม่แสดงหรือส่งออกคะแนนรวม ป้ายถูก/แพงยังเป็นข้อสรุปของบทวิเคราะห์เดิมจาก Valuation Class ใน 02_Scorecard (หรือ Conclusion ใน 04_Valuation เมื่อไม่มีค่าแรก) ไม่ได้คำนวณใหม่เมื่อราคา/งบเปลี่ยน หน้า “วิธีอ่าน Dashboard” อธิบายกรอบรายธุรกิจและข้อจำกัด พร้อมวันที่กำกับป้าย เก็บข้อมูลต้นทางเก่าใน Master เพื่ออ้างอิงย้อนหลัง
